## English

### Overview
Light-Video is an open-source video platform built with **Python** and the **Flask** framework. It provides a lightweight, easy-to-deploy web application for video browsing and playback.

### Technology Stack
- **Backend**: Python 3.x + Flask  
- **Dependencies**: Managed via `pip` (see `requirements.txt`)  
- **Default Port**: `3000`  
- **Language Support**: Chinese (UI and content are primarily in Chinese; multilingual support is not currently available)

### Quick Start
1. Clone the repository  
2. Install dependencies:  
   ```bash
   pip install -r requirements.txt
```

1. Run the application:
   ```bash
   python app.py
   ```
2. Open your browser and visit: http://localhost:3000

Notes

· All required packages are listed in requirements.txt – simply install them with pip.
· The server listens on port 3000 by default.
· This project is currently designed for Chinese-speaking users; other languages are not fully supported.

中文

项目简介

Light-Video 是一个基于 Python 和 Flask 框架开发的开源视频网站。它轻量、易部署，适合快速搭建视频浏览与播放平台。

技术栈

· 后端：Python 3.x + Flask
· 依赖管理：使用 pip 安装（依赖已写入 requirements.txt）
· 默认端口：3000
· 语言支持：界面及内容主要为中文，暂不支持多语言

快速开始

1. 克隆代码仓库
2. 安装依赖：
   ```bash
   pip install -r requirements.txt
   ```
3. 启动应用：
   ```bash
   python app.py
   ```
4. 浏览器访问：http://localhost:3000

注意事项

· 所有依赖包已整理在 requirements.txt 中，直接 pip 安装即可。
· 服务默认运行在 3000 端口。
· 项目当前面向中文用户，未做国际化适配。
